# Oink 🐷

Oink is a gamified, educational personal finance and paper-trading application designed specifically to help teenagers build financial literacy, master money basics, and practice investing in a risk-free environment.

## Key Features & Architecture

* **Gamified Learning Path:** Users progress through structured chapters and levels (ranging from money basics and inflation to high-yield savings accounts and compound interest) earning XP and maintaining daily learning streaks.
* **Real-Time Paper Trading Simulation:** Teens can manage a virtual stock portfolio, track equity growth via interactive timeline charts (1D, 1W, 1M, ALL), and execute simulated trades on live market tickers (such as AAPL and NVDA) using their virtual cash vault.
* **Daily Financial Feed & Quizzes:** Features a curated daily teen financial news feed explaining macroeconomics, interest rates, and tech trends in a relatable way, alongside interactive scenario-based challenges.
